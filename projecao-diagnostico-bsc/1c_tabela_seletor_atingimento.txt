Seletor Atingimento BSC = 
// ============================================================================
// TABELA DA BARRA "ATINGIMENTO DA META" DA PAGINA "Projeção BSC"
// Como criar: Modelagem > Nova tabela > colar este arquivo inteiro.
// NAO criar relacionamento: e uma tabela solta, usada so na segmentacao.
//
// Valores INTEIROS de 0 a 100 (80 = 80% da meta). Inteiro de proposito: a
// barra deslizante so para em valores que existem na tabela. Com decimais
// ela pode parar em 0,8234, que nao existe, e a medida voltaria a 100%.
//
// Depois de criar, na coluna Atingimento:
//   Tipo de dados: Numero inteiro
//   Formato: personalizado  0"%"   (aparece 80% em vez de 80)
//
// Segmentacao: campo Atingimento > Formatar > Configuracoes da segmentacao >
// Estilo: "Valor unico". Arraste ate 100 e salve: e o valor que o relatorio
// abre. A medida divide por 100.
// ============================================================================
SELECTCOLUMNS(
    GENERATESERIES( 0, 100, 1 ),
    "Atingimento", [Value]
)
