Como montar no seu arquivo

O painel é um visual só. Leva alguns minutos; o único trabalho de verdade é trocar os nomes das tabelas e colunas pelos do seu modelo.

  1. Crie as medidas de apoio (bloco 1 do código). O painel precisa do numerador e do denominador separados para somar por dia, semana, mês, AT e cor. Como você já tem a medida do indicador, o mais seguro é copiar dela as duas contagens, mantendo os nomes [Inst3D No Prazo] e [Inst3D Instaladas].
  2. Crie a medida principal (bloco 2) e ajuste só as 5 VARs marcadas com <<< MODELO: são as únicas que leem tabelas e colunas. A lista do que cada uma espera está em Mapa do modelo.
  3. Insira o visual HTML Content, arraste a medida para o campo de valores e deixe o visual sem título e com fundo transparente.
  4. Tamanho de referência: 1264 × 638 px, em uma página 1280 × 720 com uma faixa de filtros em cima. O painel se ajusta sozinho; a partir de cerca de 1030 px de largura ele continua inteiro (cabe ao lado de um menu lateral).
  5. Filtros da página: Mês (da dCalendario), Cor (dAT[COR_AREA ]) e AT (dAT[AREA ]). O lado direito ignora o mês por conta própria: não precisa mexer em “Editar interações”.
  6. Confira: o número grande do mês tem que ser igual ao da sua medida atual do indicador. Se não for, a diferença está nas duas medidas de apoio.

// ============================================================================
// PAINEL "INSTALACAO EM ATE 3 DIAS"  (v1)
// Um unico visual HTML Content ocupando o corpo da pagina. Fundo TRANSPARENTE.
// Mesma linguagem visual do BSC v5 e do Ranking v2.
//
// PALETA: troque so a palavra em _tema ->  "GRAFITE" | "OCEANO" | "AURORA"
//
// O PAINEL TEM DUAS METADES
//   ESQUERDA - muda com o filtro de MES e com os botoes Mes | Semana | Dia:
//     1. faixa escura com o resultado do mes do filtro (meta, distancia da
//        meta, volumes, variacao contra o mes anterior) e as 4 CORES;
//     2. CURVA do indicador: 12 meses, 12 semanas ou os dias do mes. Os tres
//        graficos ja saem prontos e o clique so troca o que aparece;
//     3. ABERTURA por COR e por AT alinhada com a curva: cada linha e uma cor
//        ou uma AT e cada coluna e o mesmo periodo do grafico (mapa de calor).
//   DIREITA - FIXA NO DIA DE HOJE (D-0), ignora o filtro de mes:
//     4. carteira pendente na carga de hoje: ja perdidas (passaram do prazo),
//        vencem hoje, vencem amanha e no prazo;
//     5. a mesma conta por COR e por AT;
//     6. lista das ORDENS, com abas Perdidas | Vencem hoje | Amanha.
//   As duas metades respeitam os filtros de COR e de AT.
//
// O QUE AJUSTAR
//   - bloco 1 (CONFIGURACAO): meta, prazo, fuso, quantos meses/semanas;
//   - VARs marcadas com "<<< MODELO": sao as UNICAS que leem tabelas, colunas
//     e medidas. Troque ali os nomes pelos do seu modelo. Todo o resto usa
//     so o que essas VARs devolvem.
//   - medidas usadas: [Inst3D No Prazo] e [Inst3D Instaladas] (arquivo
//     medidas_de_apoio_v1.txt).
//
// COMPATIBILIDADE COM O HTML CONTENT (nao executa JavaScript)
//   - so HTML + CSS; botoes com <details> + :has(), como nas paginas IFI/IRR;
//   - atributo style so carrega variaveis CSS e fica em um <div class='v'>
//     neutro; nenhum nome entra em atributo (title), so em texto;
//   - 100vh de proposito: o visual envolve o conteudo em um wrapper sem altura;
//   - nao usar aspas duplas dentro do CSS/HTML (quebram a string DAX).
// ============================================================================

// ------------------------------------------------------------------- PALETA
VAR _tema = "GRAFITE"

// d0/d1/d2 = fundos escuros | a1/a2 = cores de destaque | g1/g2 = brilhos
// pri/pri-b = destaque sobre fundo claro
VAR _tokens =
    SWITCH(
        _tema,
        "AURORA",
            "--d0:#140A2E;--d1:#22114F;--d2:#43208A;--a1:#F472B6;--a2:#A78BFA;--g1:rgba(244,114,182,.24);--g2:rgba(167,139,250,.30);--pri:#7C3AED;--pri-b:#F3EDFF",
        "OCEANO",
            "--d0:#050E26;--d1:#0A1A42;--d2:#123A7C;--a1:#22D3EE;--a2:#60A5FA;--g1:rgba(34,211,238,.22);--g2:rgba(59,130,246,.30);--pri:#2563EB;--pri-b:#E9F0FF",
        "--d0:#0C1016;--d1:#161C26;--d2:#2B3442;--a1:#7DD3FC;--a2:#CBD5E1;--g1:rgba(125,211,252,.14);--g2:rgba(148,163,184,.20);--pri:#334155;--pri-b:#EEF2F6"
    )

// ============================================================================
// 1. CONFIGURACAO  (AJUSTE AQUI)
// ============================================================================
VAR _loc = "pt-BR"
VAR _meta = 0.81              // meta do indicador (81%)
VAR _prazoDias = 3            // prazo, em dias corridos, contado da abertura
VAR _fuso = -3                // fuso de Brasilia (UTC-3)
VAR _qtdMeses = 12            // meses na curva mensal
VAR _qtdSemanas = 12          // semanas na curva semanal (segunda a domingo)
VAR _visaoInicial = "Mês"     // curva que abre primeiro: "Mês" | "Semana" | "Dia"
VAR _maxLinhas = 60           // ordens listadas em cada aba (as mais urgentes)

// Cores das areas: nome (como esta na coluna de cor), ordem na tela e classe.
VAR _coresCfg =
    DATATABLE(
        "CorCfg", STRING,
        "OrdCor", INTEGER,
        "ClsCor", STRING,
        {
            { "OURO", 1, "c-ouro" },
            { "PRATA 1", 2, "c-prata1" },
            { "PRATA 2", 3, "c-prata2" },
            { "BRONZE", 4, "c-bronze" }
        }
    )

// ============================================================================
// 2. DATAS DE REFERENCIA
// ============================================================================
// "Hoje" no fuso informado (UTCNOW e igual no Desktop e no Service).
VAR _agora = UTCNOW() + _fuso / 24
VAR _hoje = DATE( YEAR( _agora ), MONTH( _agora ), DAY( _agora ) )
VAR _hojeN = INT( _hoje )

// <<< MODELO: ultima data do filtro de periodo da pagina (segmentacao de Mes).
VAR _fimSel = MAX( dCalendario[Data] )

// Mes de referencia = mes do filtro. Sem filtro, ou com mes futuro: mes atual.
VAR _ref = IF( ISBLANK( _fimSel ) || _fimSel > _hoje, _hoje, _fimSel )
VAR _mesIni = DATE( YEAR( _ref ), MONTH( _ref ), 1 )
VAR _mesFim = EOMONTH( _ref, 0 )
VAR _mesAntIni = EDATE( _mesIni, -1 )
VAR _mesIni0 = EDATE( _mesIni, 1 - _qtdMeses )               // 1o mes da curva mensal
VAR _semRef = _ref - WEEKDAY( _ref, 2 ) + 1                   // segunda-feira da semana de referencia
VAR _semIni0 = _semRef - 7 * ( _qtdSemanas - 1 )              // 1a semana da curva semanal
VAR _janIni = MIN( _mesIni0, _semIni0 )
VAR _janFim = MAX( _mesFim, _semRef + 6 )

// ============================================================================
// 3. MODELO  (unicas VARs, junto com _fimSel, que leem o modelo)
// ============================================================================
// <<< MODELO: uma linha por AT x dia com as duas medidas de volume.
//     - ignora o filtro de mes (a curva sempre mostra a janela inteira);
//     - ignora o filtro de cor/AT (para comparar a selecao com o Geral e com
//       as cores); o filtro e aplicado depois, em memoria, com _atsCtx.
VAR _gradeModelo =
    CALCULATETABLE(
        ADDCOLUMNS(
            CROSSJOIN(
                SUMMARIZE( dAT, dAT[AREA ], dAT[COR_AREA ] ),
                VALUES( dCalendario[Data] )
            ),
            "@n", [Inst3D No Prazo],
            "@d", [Inst3D Instaladas]
        ),
        REMOVEFILTERS( dAT ),
        REMOVEFILTERS( dCalendario ),
        DATESBETWEEN( dCalendario[Data], _janIni, _janFim )
    )

// <<< MODELO: ATs que estao no filtro da pagina (cor e/ou AT selecionadas).
VAR _atsCtx = VALUES( dAT[AREA ] )

// <<< MODELO: carteira pendente = ordens de instalacao ainda sem encerramento.
//     Respeita o filtro de cor/AT e IGNORA o filtro de mes (e sempre D-0).
//     Nao tem data de agendamento? Troque a ultima linha por:  "Agenda", BLANK()
VAR _pendModelo =
    CALCULATETABLE(
        SELECTCOLUMNS(
            FILTER( 'fInstalacao', ISBLANK( 'fInstalacao'[DAT_ENCERRAMENTO] ) ),
            "Ordem", "" & 'fInstalacao'[NUM_ORDEM],
            "AT", RELATED( dAT[AREA ] ),
            "Cor", RELATED( dAT[COR_AREA ] ),
            "Abertura", 'fInstalacao'[DAT_ABERTURA],
            "Agenda", 'fInstalacao'[DAT_AGENDAMENTO]
        ),
        REMOVEFILTERS( dCalendario )
    )

// <<< MODELO: data da ultima carga da base (para avisar quando a carga de hoje
//     ainda nao entrou). Nao tem essa coluna? Troque por:  BLANK()
VAR _dataCarga = CALCULATE( MAX( 'fInstalacao'[DAT_REFERENCIA] ), REMOVEFILTERS() )

// ============================================================================
// 4. GRADE AT x DIA  ->  AT / COR / GERAL / SELECAO  x  MES / SEMANA / DIA
// Daqui para baixo nada mais consulta o modelo: e tudo soma em memoria, por
// isso os numeros fecham entre si (dia soma na semana, AT soma na cor...).
// ============================================================================
VAR _grade =
    SELECTCOLUMNS(
        FILTER( _gradeModelo, [@d] > 0 ),
        "AT", dAT[AREA ],
        "Cor", UPPER( TRIM( dAT[COR_AREA ] ) ),
        "Dia", dCalendario[Data],
        "N", COALESCE( [@n], 0 ),
        "D", [@d]
    )
VAR _gradeChaves =
    ADDCOLUMNS(
        _grade,
        "kM", DATE( YEAR( [Dia] ), MONTH( [Dia] ), 1 ),
        "kS", [Dia] - WEEKDAY( [Dia], 2 ) + 1
    )

// Uma linha por granularidade x AT x periodo. Gran: M = mes, S = semana, D = dia.
VAR _longAT =
    UNION(
        SELECTCOLUMNS(
            GROUPBY(
                FILTER( _gradeChaves, [kM] >= _mesIni0 && [kM] <= _mesIni ),
                [AT], [Cor], [kM],
                "sN", SUMX( CURRENTGROUP(), [N] ),
                "sD", SUMX( CURRENTGROUP(), [D] )
            ),
            "Gran", "M", "AT", [AT], "Cor", [Cor], "Ini", [kM], "N", [sN], "D", [sD]
        ),
        SELECTCOLUMNS(
            GROUPBY(
                FILTER( _gradeChaves, [kS] >= _semIni0 && [kS] <= _semRef ),
                [AT], [Cor], [kS],
                "sN", SUMX( CURRENTGROUP(), [N] ),
                "sD", SUMX( CURRENTGROUP(), [D] )
            ),
            "Gran", "S", "AT", [AT], "Cor", [Cor], "Ini", [kS], "N", [sN], "D", [sD]
        ),
        SELECTCOLUMNS(
            FILTER( _gradeChaves, [Dia] >= _mesIni && [Dia] <= _mesFim ),
            "Gran", "D", "AT", [AT], "Cor", [Cor], "Ini", [Dia], "N", [N], "D", [D]
        )
    )

// ---- ATs e cores: todas (com instalacao na janela) x as do filtro ----
VAR _atsTodas = GROUPBY( _grade, [AT], [Cor] )
VAR _atsVis = FILTER( _atsTodas, CONTAINSROW( _atsCtx, [AT] ) )
VAR _qtdTodas = COUNTROWS( _atsTodas ) + 0
VAR _qtdVis = COUNTROWS( _atsVis ) + 0
VAR _coresVis = GROUPBY( _atsVis, [Cor] )
VAR _qtdCoresVis = COUNTROWS( _coresVis ) + 0
VAR _corUnica = IF( _qtdCoresVis = 1, MAXX( _coresVis, [Cor] ) )
VAR _qtdDaCorUnica = COUNTROWS( FILTER( _atsTodas, [Cor] = _corUnica ) ) + 0

// Contexto do filtro: G = geral | C = uma cor inteira | A = uma AT | S = selecao
// de varias ATs | V = nada no filtro tem instalacao na janela.
VAR _ctx =
    SWITCH(
        TRUE(),
        _qtdVis = 0, "V",
        _qtdVis = _qtdTodas, "G",
        _qtdVis = 1, "A",
        _qtdCoresVis = 1 && _qtdVis = _qtdDaCorUnica, "C",
        "S"
    )
// Serie "principal" = a que vira a curva e o numero grande.
VAR _entPrincipal =
    SWITCH( _ctx, "G", "#G", "A", "A:" & MAXX( _atsVis, [AT] ), "C", "C:" & _corUnica, "#S" )
VAR _nomeCtx =
    SWITCH( _ctx, "G", "Geral", "A", "AT " & MAXX( _atsVis, [AT] ), "C", _corUnica, "V", "Sem dados", "Seleção" )
VAR _subCtx =
    SWITCH(
        _ctx,
        "A", _corUnica,
        "V", "nenhuma instalação no filtro",
        _qtdVis & IF( _qtdVis = 1, " AT", " ATs" )
    )
VAR _clsCtx = COALESCE( MAXX( FILTER( _coresCfg, [CorCfg] = _corUnica ), [ClsCor] ), "c-geral" )

// ---- series: Geral, selecao, cada cor (inteira) e cada AT do filtro ----
VAR _longNoFiltro = FILTER( _longAT, CONTAINSROW( _atsCtx, [AT] ) )
VAR _series =
    UNION(
        SELECTCOLUMNS(
            GROUPBY( _longAT, [Gran], [Ini], "sN", SUMX( CURRENTGROUP(), [N] ), "sD", SUMX( CURRENTGROUP(), [D] ) ),
            "Ent", "#G", "Gran", [Gran], "Ini", [Ini], "N", [sN], "D", [sD]
        ),
        SELECTCOLUMNS(
            GROUPBY( _longNoFiltro, [Gran], [Ini], "sN", SUMX( CURRENTGROUP(), [N] ), "sD", SUMX( CURRENTGROUP(), [D] ) ),
            "Ent", "#S", "Gran", [Gran], "Ini", [Ini], "N", [sN], "D", [sD]
        ),
        SELECTCOLUMNS(
            GROUPBY( _longAT, [Gran], [Cor], [Ini], "sN", SUMX( CURRENTGROUP(), [N] ), "sD", SUMX( CURRENTGROUP(), [D] ) ),
            "Ent", "C:" & [Cor], "Gran", [Gran], "Ini", [Ini], "N", [sN], "D", [sD]
        ),
        SELECTCOLUMNS(
            _longNoFiltro,
            "Ent", "A:" & [AT], "Gran", [Gran], "Ini", [Ini], "N", [N], "D", [D]
        )
    )

// ---- periodos de cada curva ----
// Rot = rotulo do eixo | RotM = rotulo medio (resumo) | RotL = rotulo longo (dica)
VAR _perM =
    SELECTCOLUMNS(
        ADDCOLUMNS( GENERATESERIES( 1, _qtdMeses ), "@i", EDATE( _mesIni, [Value] - _qtdMeses ) ),
        "Gran", "M",
        "Ord", [Value],
        "Ini", [@i],
        "Fim", EOMONTH( [@i], 0 ),
        "Rot", FORMAT( [@i], "MMM/yy", _loc ),
        "RotM", FORMAT( [@i], "MMM/yy", _loc ),
        "RotL", FORMAT( [@i], "MMMM/yyyy", _loc ),
        "Fds", 0
    )
VAR _perS =
    SELECTCOLUMNS(
        ADDCOLUMNS( GENERATESERIES( 1, _qtdSemanas ), "@i", _semIni0 + 7 * ( [Value] - 1 ) ),
        "Gran", "S",
        "Ord", [Value],
        "Ini", [@i],
        "Fim", [@i] + 6,
        "Rot", FORMAT( [@i], "dd/MM", _loc ),
        "RotM", "sem. " & FORMAT( [@i], "dd/MM", _loc ),
        "RotL", "semana de " & FORMAT( [@i], "dd/MM", _loc ) & " a " & FORMAT( [@i] + 6, "dd/MM", _loc ),
        "Fds", 0
    )
VAR _perD =
    SELECTCOLUMNS(
        ADDCOLUMNS( GENERATESERIES( 1, DAY( _mesFim ) ), "@i", _mesIni + [Value] - 1 ),
        "Gran", "D",
        "Ord", [Value],
        "Ini", [@i],
        "Fim", [@i],
        "Rot", FORMAT( [@i], "dd", _loc ),
        "RotM", FORMAT( [@i], "dd/MM", _loc ),
        "RotL", FORMAT( [@i], "ddd, dd/MM", _loc ),
        "Fds", IF( WEEKDAY( [@i], 2 ) >= 6, 1, 0 )
    )
VAR _per = UNION( _perM, _perS, _perD )

// ---- serie principal em cada periodo ----
VAR _seriePrincipal = FILTER( _series, [Ent] = _entPrincipal )
VAR _serieP0 =
    ADDCOLUMNS(
        _per,
        "pN",
            VAR _gN = [Gran]
            VAR _iN = [Ini]
            RETURN SUMX( FILTER( _seriePrincipal, [Gran] = _gN && [Ini] = _iN ), [N] ),
        "pD",
            VAR _gD = [Gran]
            VAR _iD = [Ini]
            RETURN SUMX( FILTER( _seriePrincipal, [Gran] = _gD && [Ini] = _iD ), [D] )
    )
VAR _serieP = ADDCOLUMNS( _serieP0, "P", DIVIDE( [pN], [pD] ) )

// ---- escala de status: resultado / meta ----
// >= 100% da meta | 90-99% | 80-89% | < 80%   (mesma escala do BSC)
VAR _lim90 = _meta * 0.90
VAR _lim80 = _meta * 0.80

// ============================================================================
// 5. FAIXA DO PERIODO (mes do filtro)
// ============================================================================
VAR _regMes = FILTER( _seriePrincipal, [Gran] = "M" && [Ini] = _mesIni )
VAR _mesN = SUMX( _regMes, [N] )
VAR _mesD = SUMX( _regMes, [D] )
VAR _mesP = DIVIDE( _mesN, _mesD )
VAR _regAnt = FILTER( _seriePrincipal, [Gran] = "M" && [Ini] = _mesAntIni )
VAR _antP = DIVIDE( SUMX( _regAnt, [N] ), SUMX( _regAnt, [D] ) )
VAR _difAnt = IF( NOT ISBLANK( _mesP ) && NOT ISBLANK( _antP ), _mesP - _antP )
VAR _ultDia = MAXX( FILTER( _grade, [Dia] >= _mesIni && [Dia] <= _mesFim ), [Dia] )
VAR _mesEmAndamento = _mesFim >= _hoje
VAR _mesRot = FORMAT( _mesIni, "MMMM/yyyy", _loc )
VAR _tierMes =
    SWITCH( TRUE(), ISBLANK( _mesP ), "tN", _mesP >= _meta, "tG", _mesP >= _lim90, "tY", _mesP >= _lim80, "tO", "tR" )
VAR _chipMes =
    SWITCH(
        TRUE(),
        ISBLANK( _mesP ), "sem dados",
        _mesP >= _meta, "▲ " & FORMAT( ( _mesP - _meta ) * 100, "0.0", _loc ) & " p.p. acima da meta",
        "▼ " & FORMAT( ( _meta - _mesP ) * 100, "0.0", _loc ) & " p.p. abaixo da meta"
    )
// Quantas instalacoes no prazo sobraram (+) ou faltaram (-) para a meta do mes.
VAR _saldoMeta = IF( ISBLANK( _mesD ), BLANK(), _mesN - _meta * _mesD )

VAR _heroResultado =
    "<div class='hz hk " & _tierMes & "'>" &
        "<span class='kk'>Instalação em até " & _prazoDias & " dias</span>" &
        "<div class='kv'><b>" & IF( ISBLANK( _mesP ), "—", FORMAT( _mesP, "0.0%", _loc ) ) & "</b><span class='chip'>" & _chipMes & "</span></div>" &
        "<span class='ks km'><b>" & _mesRot & "</b>" &
            IF( _mesEmAndamento && NOT ISBLANK( _ultDia ), " · parcial até " & FORMAT( _ultDia, "dd/MM", _loc ), "" ) &
            " · meta ≥ " & FORMAT( _meta, "0.0%", _loc ) & "</span>" &
        "<span class='ks'>" &
            SWITCH(
                TRUE(),
                ISBLANK( _saldoMeta ), "sem instalações concluídas no mês",
                _saldoMeta >= 0, "folga de <b>" & FORMAT( ROUNDDOWN( _saldoMeta, 0 ), "#,0", _loc ) & "</b> instalações no prazo sobre a meta",
                "faltam <b>" & FORMAT( ROUNDUP( - _saldoMeta, 0 ), "#,0", _loc ) & "</b> instalações no prazo para a meta"
            ) & "</span>" &
    "</div>"

VAR _heroVolumes =
    "<div class='hz hv'>" &

        VAR _lo = MIN( COALESCE( _minV, _meta ), _meta ) - 0.01

        VAR _yMin = MAX( 0, ROUNDDOWN( ROUND( _lo / _passo, 6 ), 0 ) * _passo )

                    "</span>"
                RETURN
                    IF(
                        ISBLANK( _pv ),
